# Звёздное небо — этап 1 (статическая страница)

Сервис формирует карту звёздного неба для выбранного места, даты и времени.
На этапе 1 страница без backend'а генерирует **.ssc-сценарий для Stellarium**:
пользователь открывает его в установленном Stellarium и сохраняет PNG (Ctrl+S).
На этапе 2 backend будет сам рендерить PNG 1920×1080 (взгляд на юг, FOV 180°).

## Структура

```
frontend/                 статический сайт (GitHub Pages)
├── index.html            разметка: круг с картой неба, поля «Место / Дата / Время», кнопка «Показать небо»
├── styles.css            тёмная тема, пилюлеобразные поля, адаптив от 360 px
├── app.js                логика: справочник городов, парсинг координат/ссылок, валидация, UTC, генерация .ssc
├── cities.json           статический справочник: 17 городов (координаты, часовой пояс, slug)
└── favicon.svg
.github/workflows/deploy-pages.yml   публикация каталога frontend/ на GitHub Pages
```

## Локальный запуск

Страница запрашивает `cities.json` через `fetch`, поэтому открывать её нужно по HTTP(S),
а не двойным щелчком по файлу (геолокация тоже требует безопасный контекст — localhost подходит):

```bash
cd путь/к/репозиторию
python3 -m http.server 8000 -d frontend
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите файлы (ветка `main`).
2. В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy-pages.yml` опубликует каталог `frontend/` при каждом push в `main`.
   Сайт будет доступен по адресу `https://<username>.github.io/<repo>/` (HTTPS).

Альтернатива без GitHub Actions: положить файлы в корень репозитория и выбрать
**Settings → Pages → Deploy from a branch → main / (root)**.

## Что реализовано (этап 1)

- Поле «Место»: 17 городов из справочника `cities.json` либо режим «Другое место / координаты».
  Принимаются десятичные координаты (`56.858398, 35.910746`), ссылки Яндекс Карт (`ll=`, `pt=` —
  порядок «долгота, широта» меняется автоматически; `pt` приоритетнее) и ссылки Google Maps
  (`@lat,lon`, `!3d!4d`, `q=`/`query=`). После распознавания поле нормализуется к `широта, долгота`.
- Кнопка «Найти в Яндекс Картах» открывает `https://yandex.ru/maps` в новой вкладке.
- Геолокация при загрузке: при разрешении подставляются координаты пользователя
  (если они близки к городу справочника — выбирается город), при отказе — Москва.
- Дата `ДД.ММ.ГГГГ` от 01.01.0000 до текущей (пралептический григорианский календарь,
  будущие даты и несуществующие даты отвергаются); время `ЧЧ:ММ`, для сегодняшней даты —
  не позже текущего.
- Локальное время места переводится в UTC: для городов — по зоне IANA (с учётом исторических
  смещений), для произвольных координат — пояс оценивается по долготе (отмечается в подсказке).
- «Показать небо» скачивает `sky-{город-или-координаты}-{ГГГГ-ММ-ДД}-{ЧЧ-ММ}.ssc`:
  наблюдатель по координатам, UTC-дата, атмосфера/Млечный Путь/Луна/планеты вкл,
  названия созвездий выкл, взгляд на юг, FOV 180°.
- Публичное API для тестов: `window.SkyService` (`parsePlace`, `parseDateStr`, `parseTimeStr`,
  `localToUtcMs`, `buildSsc`, `validate` и др.).

## Требования к окружению

- Современные Chrome, Firefox, Safari, Edge; адаптив от 360 px.
- HTTPS (GitHub Pages выдаёт сертификат автоматически).

## Этап 2 (план)

Backend: headless-Stellarium рендерит PNG 1920×1080 (панорама, юг, FOV 180°, атмосфера,
Млечный Путь, Луна и планеты; без интерфейса), изображение не хранится и отдаётся пользователю.
